# Shadow 1.4.1 EVA instruments

The right field follows EVA's `build_sq_sport` gear frame and bilingual captions,
`build_square` speed/unit hierarchy, and `EVAHAZARD` diagonal 36px stripe pitch.
The decoration lives on the transparent text canvas; all three source PNGs and
all three baked photo RGBA files remain byte-for-byte unchanged. Layouts are
generated by `tools/shadow_layout.py` from `tools/shadow_geom.py`.

The shared EVA theme supplies red `#FF1100` and yellow `#FFDD00`. Shadow averages
their RGB channels, darkens by 15%, and gives blue a 26/255 floor to soften the
saturation: main ink `#D9651A`. Secondary ink is 88% of that: `#BF5917`.
Campaign orange `#FF6A00` marks the frame and hazard strip; Comfort's unlit bar
uses navy `#14284B`. Red appears only in lit 7000–8000 rpm segments. The bar has
32 segments of 250 rpm, so the redline starts exactly at segment 28.

Sport and Comfort put RANGE, WATER / 水温, and TIME captions above three separate
readings. Eco reserves the entire 412px field for its RPM bar, stacks the large
gear frame beside range and time, and retains space for a three-digit speed.
The gear shows the actual D/M/S drive letter and numeral, or P/R/N alone, including
while stopped. It inherits neither shift-point red nor animated glyph scaling.

The bottom status row (y 640–720, below the photo) is black except x 1380–1460,
y 660–720. That cell is BMW's gear letter. Covering the letter is what makes the kombi paint a black box on
top of the theme (Cluster Themes `minimal.json`, the same coordinates). The
seat-belt lamp is drawn by the kombi above the panel and stays visible.

Real, unscaled atlases used: `sq_speed`, `sqs_speed`, `gear`, `b_gear`, `d_aen`,
`d_line`, `d_label`, `d_unit`, `d_num42`, `sqs_num64`, `time70`. The preview font
preparer copies only these existing local EVA atlases into the **gitignored**
Shadow fonts directory, after checking every destination with Git. It never
bakes substitutes or writes font data to tracked paths.

Preview at 96 km/h, 4550 rpm, D4, 498 km, 88°C, 14:32:

```powershell
python -X utf8 tools/shadow_layout.py
python -X utf8 tools/bake_shadow_preview_fonts.py
# Use your local SDK; for simulation this can be oap-sdk.bench-stub.
python -X utf8 kit/tools/build.py shadow_dash
node tools/render_shadow.js dist/shadow-preview --stills-only
node bench/test/shadow_dash_test.js
```

The renderer exercises the built app, exports each full PNG plus a nearest-neighbour
2× right crop, checks the real atlas glyph bounds (including three-digit speeds
and alternate gear captions), and verifies every pixel at y=636–719 is pure black.
No commercial source fonts or derived font atlases belong in a commit.
