# EVA 仪表的设计

单仪表（Dash only）时 HUD 交回 BMW 原厂。在这个前提下重做仪表，加更多 EVA 元素。菜单 **Dash design** 随时切换九种新设计，原来的设计留作 Original。

## 车主定下的

- 保留 A、B、D，去掉波形方案 C。
- 报警效果不变，种类和 HUD 一样是六种。
- A 的 MAGI 配色和样子保留，但不能接报警规则，因为全屏报警会盖住它。
- A 的挡位数字放在框的正中，比方案页的示意靠上。
- B 的中间可以选续航或时间。
- D 不要 MAGI，那个位置显示实时转速。
- P、R、N 显示 出撃待命、緊急撤退、同期解除，和 HUD 一致。

- Mode 里加 By drive mode：Comfort、Sport、Eco Pro 各自选关闭、HUD、仪表或两者同时，仪表设计也分开选。这改掉了之前“驾驶模式不切换模式”的约定，只在选了 By drive mode 时生效。

- 第一次上车发现 `map` 在 BMW 表盘下面，只有工字形区域清楚可见，车主要求完整重新设计。
- 第3新東京市 放在 BMW 的 M440i 标志正下方，受黑化影响的设计都要改。
- Demo 一轮：10 秒复杂的数据变化，然后每种报警走一遍，每个 2 秒。
- 三个驾驶模式的 BMW 表盘只有颜色不同，共用这个可见区。
- Sport 用橙色，Eco Pro 用蓝色，Comfort 用橙加白。
- 新增 Comfort、Eco Pro 各两个中间方案和一个全屏方案，多用中二文案。
- 发现的 bug 该修就修，方案定了直接开工。
- 菜单改成一个总开关选 HUD、Dash、HUD + Dash。HUD only 时按驾驶模式选 HUD 造型，Dash only 时按驾驶模式选仪表，HUD + Dash 时两个都按驾驶模式选。

## 实现时我定的

- 工字形设计投 `map`。我在 0.5.0 试过投 `panel`，上车后发现它盖住 BMW 的数字车速，右侧 BC 区也不能用，车主指出涂层跑到了最上面，所以 0.5.1 改回 `map`。
- 工字形设计的报警收进中间 584×444，不会被 BMW 挡住，标题比 0.5.0 小。
- 第二次上车发现 BMW 表盘两侧的黑化比第一次量的宽，可见区收窄到 x 205–850，所有工字形设计重排。电源灯离开左上，A 的三块变窄。
- B 的七段数字和 C1 的时间略缩小并右移，E1 的油耗略缩小，都避开 BMW 从左边伸进来的白线。
- 默认仍是 Original。
- 去掉 By drive mode：每个画面选项都有“关闭”，HUD + Dash 就能组合出它的全部效果，0.5.0 的设置会自动迁移。行按 Mode 显示和隐藏（`app.json` 的 `showWhen`）。
- HUD + Dash 的 HUD 默认仍是 Battle display（`eva`），HUD only 默认每个驾驶模式用自己的版面，升级后画面不变。
- 车还没报告驾驶模式时统一按 Comfort，最常用，启动时少重画一次。之前 HUD only 是先显示 Sport。
- 工字形设计给 BMW 弹窗让路，因为 `panel` 在弹窗上面。
- 新方案的文案只用 app 现有的六组标语和菜单里的英文，heaven 的英文补全了下半句。第一次写方案页时被安全系统中断，所以没有写新文案；车主可以再给。
- A 的 MAGI 三块排成一行，巨大挡位变小，活動限界去掉，因为 BMW 底行已有续航。
- B 的电源灯只亮当前状态，放在左上还露出来的地方。
- 所有带标语的设计共用菜单 **EVA message**，不再各有默认值。
- C2 的两行标语每组都烘一个字号，放到宽度允许的最大。
- C3 的竖排是每个字一个小部件，长音符 ー 用 ｜ 代替。
- E1 的段条和 E2 的圆环按 20 L/100km 为满。
- MAGI 阈值：油温 80 / 130°C，水温 70 / 110°C。80°C 来自现有的冷车保护，其余可以改。
- B 的续航小数位固定为 0，因为车上的续航是整数公里。
- D、E3 的 NERV 标志放在车速标题那一行，避开仪表罩挡住的左上角和转速条。
